## Building now

**[Helme](https://helme-web.vercel.app)** runs a team of AI coding agents on one Windows PC: a Chief of Staff that plans, one agent per project, a Reviewer that checks every change before merge, and one list of what waits for me. It is how I build everything above. Helme is in private use today; the website only introduces it ([source](https://github.com/sinhgiang/helme-web)).

## How I work

- I own the product: the spec, the decisions and the final review. AI coding agents write, test and review the code under rules I set.
- Every change goes through its own branch, automated tests and a review before it is merged and shipped.
- I ship with TypeScript, Next.js, Electron, Flutter, Supabase, Vercel and Codemagic.
